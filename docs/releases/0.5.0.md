# WIND 0.5.0 release notes

Version 0.5.0 aligns evaluation scores with their mathematical definitions and
makes completion, abort and export states explicit. Results use `metrics_v2`,
`local_series_v2` and export schema 2. Historical files retain their original
meaning; they are not automatically relabelled or recalculated.

## Evaluation changes

QueryEfficiency now measures queries to a configured accuracy, including an
initial hit at zero queries. Recovery events retain immediate recoveries and
censored windows. DynamicRegret always reports the raw cumulative sum, with
path normalization as a separate value. AsymptoticBound is a finite-horizon
ensemble estimate, not a scalar inferred from one trajectory.

StiefelGeodesic is a numerical canonical-metric estimate, separate from frame
Frobenius and Grassmann principal-angle distances. Solver failure is explicit;
the implementation does not certify a globally shortest path for every pair.
Exact definitions, aggregation rules and migration examples are in
[the metric reference](../metrics_v2.md).

## Execution and compatibility

Aborted sessions cannot release evaluator records. Repeated Gymnasium close
calls are safe; scheduled oracles and metric accumulators reset completely.
The ordinary runner restores the caller's NumPy and Python random states.
Environment/oracle registration no longer retains large paths through an
ownership cycle. Isolation remains a local Python API contract, not an OS sandbox.

Canonical optimizer implementations live in `optimizers.py`; historical aliases
live in `optimizer_compat.py`. Existing imports through `experiment.py` remain
available. Optimizer updates, alias defaults and random-stream identities are
preserved. New reports include exact metric identities, statuses and counts;
JSON uses null for undefined values.

## Distribution and validation

The wheel contains the web interface, while the source checkout keeps `web/`
as the shared source for local use and GitHub Pages. Installed-wheel experiments
write to the current working directory, not the package installation directory.
Private checks, manuscripts, legacy archives and run outputs are excluded from
the Python distribution. Historical public results remain in the Git repository.

The migration comparison covers 5010 evaluation runs per version across memory,
zeroth-order and dimension studies, with 30 evaluation seeds and separate tuning.
All common fields in the 18 original tables agree. This is a comparison with the
pre-0.5.0 local snapshot, not a reinterpretation of older published archives.
Corrected metric definitions are additionally tested on independent examples.

The standard suite evaluates supplied parameter configurations without automatic
tuning: divergence on difficult tasks remains a reported outcome. Full standard
and full RL studies are separate from the migration validation. Publication runs
should use fresh result directories and retain source hashes and manifests before
the accompanying manuscript is finalized.
