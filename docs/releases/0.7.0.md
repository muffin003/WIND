# WIND 0.7.0 — catalog_v2

This release contains 22 source-specified algorithms. It adds AdaGrad,
OnePointSPSA, spherical forward-difference ZOSignSGD, fresh-comparison
RandomSearch and constant-coefficient AcceleratedSPSA. Definitions and tests
are in [the algorithm reference](../algorithms_070.md).

SPSA now means the normalized Bernoulli tracking variant with one minus-plus
pair, no factor d, parameters `alpha` and `beta`. It is intentionally different
from classical SPSA. Old `lr/h/m` SPSA configurations are rejected, not migrated.
The unchanged central-coordinate implementation is named `KieferWolfowitz`;
`CoordinateFiniteDifferenceSGD` is no longer an accepted name or import.
No historical aliases are introduced. Four excluded methods remain excluded:
QuadraticInterpolation, distributed Nedic subgradient, CMA-ES and GP-UCB.

`wind_tracking_v1` tasks, generators, budgets, splits and specification hash
remain unchanged. The reference roster is catalog_v2: 22,450 compatible runs
and at most 89.8 million queries. Canonical settings are fixed, never tuned.
Manifest records both the catalog and reference implementation identities.
`metrics_v2` and `local_series_v2` remain in force.

New result exports use schema 4. Historical schema-3 canonical results remain
readable and validatable without rewriting their labels, numbers or manifests.
Configuration schema remains 3, with strict current algorithm identifiers.
An optional `AdvanceResult.estimation_point` describes a public estimator center;
it contains no evaluator information. RandomSearch has no estimated gradient.

Paper protocol is `paper_tracking_v4`: AdaGrad joins memory; four new ZO methods
join zeroth and dimension. See [the fixed development protocol](../paper_tracking_v4.md).
RL protocol and computations are unchanged. Source labels and package versions
do not determine RNG; original generator tokens are retained explicitly.

Historical 0.6 results are not 0.7 reference scores. Source snapshots, old wheels,
dependency locks and result checksums stay in private legacy/internal checks.
## Reproduction inputs and subsequent fixes

The canonical, five paper studies and replicated Q-learning/PPO runs have been
completed locally. This Git publication provides reproduction inputs rather than
the new full result arrays or policies. See the [reproduction kit](../../reproducibility/0.7.0/README.md)
for fixed dependencies, source fingerprints and commands. Historical tracked
results are not relabelled as 0.7.0 scores.

The final source includes the per-query ensemble-grid validation fix and
configurable RL spawn workers. Canonical/paper used the earlier 0.7.0 build;
RL used the final build. The kit can reconstruct either source snapshot without
changing the active package. These archival source variants are not algorithm
aliases. The fixed OnePointSPSA tuning grid and its TUNING_FAILED outcomes are
preserved. No additional tuning or full reruns are performed for this publication.
